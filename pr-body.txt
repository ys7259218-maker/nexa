## Changes
The root layout now declares a dark `theme-color` viewport (`#09090b`) so mobile browsers paint their address bar / status bar chrome to match the app's zinc-950 background instead of flashing white or defaulting to the OS theme.

Uses the current Next.js `export const viewport` API (the `metadata.themeColor` form is deprecated as of Next 14).

## Notes
- Display-only change; metadata/layout `lang`, titles, and description all unchanged.
- Contract test guards the fix and rejects the deprecated `metadata.themeColor` placement.
