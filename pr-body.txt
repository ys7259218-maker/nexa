Puts the outbound delivery health front and center: the dashboard's analytics cards now show an **Outbound delivered** rate, computed from the exact funnel, linking through to the delivery-funnel page.

## What changes
- `lib/dashboard.ts`:
  - `DashboardSnapshot` gains `deliveredRatePercent` and `readRatePercent` (nullable).
  - `getDashboardSnapshot` adds an owner-scoped `messages.status` query for outbound rows and derives the rates via the existing `computeDeliveryFunnel` (null when there are no outbound messages yet).
- `components/dashboard/AnalyticsCards.tsx`:
  - `AnalyticsStat` gains an optional `href`; stat cards render as links when present.
- `components/dashboard/Dashboard.tsx`:
  - New "Outbound delivered" card (`{deliveredRatePercent}%`, "`{readRatePercent}% read`") linking to `/delivery-funnel`; shows "—" with a "No outgoing messages yet" note when null.

## Tests
- Dashboard loader tests: delivered/read rates derived from mocked outbound statuses, nulls when no outbound messages, updated query-table list.
- UI-contract: AnalyticsCards link support, Dashboard stat wiring/href, loader fields.
- `npm run check` green: 347 node tests + 4 issue-reports, lint/typecheck/build clean.
