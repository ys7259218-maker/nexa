## Changes
The workspace navbar quick links (Dashboard, Inbox, AI Employees, Team) now announce the current page with `aria-current="page"`, matching the treatment the sidebar already had. Uses the same `usePathname()` prefix rule as the sidebar, so nested routes (e.g. `/ai-employees/abc`) keep their parent shortcut marked current.

## Notes
- Accessibility-only change; no visual or logic change.
- Contract test asserts every shortcut opts into `aria-current`.
