Approved drafts now show a clear success indicator once sent, with free-form/template distinction and a masked provider id.

## What changes
- `lib/conversations.ts`:
  - `ConversationMessage` now includes `template_name: string | null`.
  - New `maskOpaqueId(value)` helper for provider message ids (shows only the tail segment).
- Conversations inbox: an outbound bubble whose `status === "sent"` renders a green "Sent" checkmark alongside the send method (`free-form` or `template "<name>"`), a masked `wa_message_id`, and the `sent_at` timestamp. Draft bubbles (and plain inbound/other-status messages) still render as before.

## Tests
- `maskOpaqueId` unit tests (tail masking, short values passed through).
- UI-contract assertions for the sent indicator, template/free-form labelling, and `maskOpaqueId` usage.
- `npm run check` green: 329 node tests + 4 issue-reports, lint/typecheck/build clean.
