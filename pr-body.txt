## Changes
The shared `Button` component inherited the HTML default of `type="submit"`. Any `Button` used with `onClick` (and no `type`) would submit its enclosing form if one ever surrounds it — a latent footgun that today is benign only because those buttons happen to live outside forms (AIEmployeeCard, GeneralSettings delete, WhatsAppSetup assign, WorkspaceKillSwitch, ConversationSafetyControl).

`Button` now defaults to `type="button"`. Form submit buttons already declare `type="submit"` explicitly everywhere (`VoiceSettings`, `KnowledgeBase`, `GeneralSettings`, `PhoneSetup`, `WhatsAppSetup`), so nothing changes visually or behaviourally — but an accidental future nesting can no longer trigger a surprise submit.
