## Changes
Two accessibility gaps in the onboarding preview flow:

- `CapabilityChip` toggles announced their selected state only visually (`✓`, border, color), which screen reader users could not perceive. The button now sets `aria-pressed={selected}`, so the toggle state is announced.
- The business-description `textarea` had only a placeholder — no label. Screen reader users got no programmatic hint about the field's purpose. Added `aria-label="Describe your business for the preview"`.

## Notes
- Display-only / semantics-only change; no behavior or layout touched.
- Onboarding is a preview-only flow and does not save anything; the existing char counter (`0/1000`) is unchanged.
