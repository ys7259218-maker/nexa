## Changes
Anyone mistyping a password on login, signup, or password reset could not verify what they typed — the inputs were permanently `type="password"`. On a 12+-character password (signup/reset enforce that) a single wrong character is easy and frustrating.

Every password field now has a reveal toggle:

- New `components/auth/PasswordToggle.tsx`: a `type="button"` that flips `aria-pressed` and announces "Show password" / "Hide password" — screen-reader users get the same control as everyone else.
- The toggle switches the input to `type="text"` while revealed and back to `type="password"` on hide.
- Applied to `LoginForm` (login), `SignupForm` (signup), and both fields of `ResetPasswordForm` (new password + confirm).
- `ForgotPasswordForm` needs none (email only).

## Notes
- Label/id/autocomplete/validation untouched — the reveal only changes visibility of the input value.
- Inputs keep `pr-16` so the toggle never overlaps typed text.
- New contract test pins the toggle semantics and that all three forms wire it in.
