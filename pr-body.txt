## Changes
The AI Employee card renders an `Avatar` with an initials letter directly beside the employee's name in an `<h2>`. Without an image the avatar output a bare character ("M", "S", …) that screen readers announced as a stray letter; with an image it would repeat the name already spoken by the heading.

The avatar is now `aria-hidden`, so screen readers hear only the employee's name from the heading — the avatar stays purely decorative, matching what it looks like.

## Notes
- Code-only; no visual change.
- `Avatar` has a single consumer (`AIEmployeeCard`), always accompanied by the textual name.
