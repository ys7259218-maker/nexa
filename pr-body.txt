Operators get visibility into customer consent: a read-only **opted-out customers** page scoped to the signed-in owner.

## What changes
- `lib/optedOutCustomers.ts`:
  - `listOptedOutCustomers(client)` — RLS-scoped read of conversations with `customer_opted_out_at` set, newest opt-out first.
  - `optOutSourceLabel(source)` — human labels for `whatsapp_keyword` / `system`.
- `app/opted-out/page.tsx` — per-customer rows: masked customer id (link into the conversation), "Opted out" chip, source chip, opt-out time and last-message time; empty and error states.
- `components/dashboard/Sidebar.tsx` — "Opted-out customers" link under Pending approvals.

## Design
- Read-only on purpose: opt-outs are honored, the moment a customer sends a stop keyword, and are never silently cleared by the UI.

## Tests
- Unit: opted-out query (not-null filter + descending order), DB-error mapping, source labels.
- UI-contract: page rows/masking/source chip/read-only copy, sidebar link, helper shape.
- `npm run check` green: 348 node tests + 4 issue-reports, lint/typecheck/build clean.
