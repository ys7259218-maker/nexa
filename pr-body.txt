Workspace-scoped, read-only audit log for human-approved outbound sends.

## What changes
- `lib/auditEvents.ts`:
  - `AuditEvent.entity_type` now includes `'message'`.
  - New `listWorkspaceAuditEvents(client, { entityType?, limit })` reads the most recent audit rows visible to the caller (RLS-gated by the existing workspace-members policy; bounded 1–100, optional entity-type filter).
  - `outbound_message_sent` registered in `auditActionLabel` ("Message sent") and `auditEventDetail` ("A human-approved outbound message was sent via template \"…\"/free-form text", with wamid).
- New `app/settings/audit/page.tsx`: auth-gated server page listing outbound-send audit events in reverse-chronological order with per-row template reference, free-form/template label, and timestamp; read-only, with empty/error states.
- `Sidebar.tsx`: new "Audit log" entry (`/settings/audit`).

## Tests

- `lib/uiContracts.test.ts`: audit page + helper + sidebar contract; metadata title entry.
