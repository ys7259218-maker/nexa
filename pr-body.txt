## Changes
Four loading shells (`/dashboard`, `/ai-employees`, `/ai-employees/[id]`, `/ai-employees/[id]/knowledge/sources`) rendered a bare skeleton with no sidebar or navbar, while every other shell already wrapped in the authenticated AppLayout. Because the real pages do wrap in AppLayout, navigating to those sections made the whole chrome flash away during the loading state, then reappear.

All ten loading shells now wrap in AppLayout so the shell keeps the sidebar, navbar, and skip-link stable while content streams in. Busy regions (`aria-busy` + `aria-label`) are unchanged.

## Notes
- Display-only change; no layout or data logic touched.
- Contract test now asserts every loading shell imports and renders AppLayout.
