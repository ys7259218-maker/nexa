Pending-draft approve-and-send now shows how long free-form sending stays legal.

## What changes
- `lib/conversations.ts`: `serviceWindowRemainingMs(lastInboundAt)` (milliseconds until the 24h customer-service window closes, null when closed/unusable) and `formatWindowRemaining(ms)` ("2h 04m" / "37m").
- Conversations inbox: draft bubble now reads "Review and approve this draft to send it. Free-form window closes in 4h 12m." (or "under a minute"), so the operator knows when a draft must switch to template mode.

- UI contract assertions for the new copy and helper usage.
