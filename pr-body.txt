Actionable workspace items now appear directly on the dashboard, not just as a count badge in the header.

## What changes
- `app/dashboard/page.tsx`: passes the full `getNotifications()` items to `<Dashboard>` (null on load error, so the panel is simply omitted).
- `components/dashboard/Dashboard.tsx`:
  - New `notificationItems` prop.
  - An **"Attention needed"** panel rendered above analytics when items exist: each item shows its priority-tone dot, title, detail, links to its action area, and a "View all notifications" shortcut to `/notifications`.
  - Renders nothing when the list is empty or unavailable.

## Tests
- UI-contract assertions: dashboard page forwards items, the panel renders per-item links with tone dots and the notifications shortcut.
- `npm run check` green: 339 node tests + 4 issue-reports, lint/typecheck/build clean.
