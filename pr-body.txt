## Changes
The dashboard's framer-motion entrance and hover animations now respect `prefers-reduced-motion`.

Framer Motion animates via JS inline styles, so the CSS `prefers-reduced-motion` rule in `globals.css` never touched them — users who asked for reduced motion still got the full fade/slide/stagger/hover-lift on the dashboard, metrics cards, and quick actions.

Wrapping the dashboard tree in `<MotionConfig reducedMotion="user">` makes Framer skip transform/opacity animations for those users while keeping them for everyone else.

## Notes
- Code-only; no visual change for users without reduced-motion (animations unchanged there).
- One wrapper in `Dashboard.tsx` covers all descendant `motion` elements (`AnalyticsCards`, `QuickActions`).
- Contract test pins the `MotionConfig reducedMotion="user"` wrapper.
