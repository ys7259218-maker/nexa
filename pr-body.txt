## Bounded inbox & opted-out queries

Keeps the inbox and opted-out pages correct past Supabase's 1,000-row default by
capping every unbounded query, while adding deep-link and exact-total fallbacks so
nothing is silently hidden.

### Inbox (`lib/conversations.ts`, `app/conversations`)
- `getConversationInbox` now runs its queries bounded:
  - conversations list: `CONVERSATIONS_LIST_LIMIT = 200`
  - message thread: `INBOX_MESSAGES_LIMIT = 300`, fetched newest-first then
    reversed back to chronological order so only the oldest turns can fall off.
- Deep links: when the `?conversation=` id is not in the capped list, the
  conversation is fetched directly by id
  (`.select("*").eq("id", …).maybeSingle()`) and appended to the list, so
  opening an older thread never breaks because of the new cap.

### Opted-out customers (`lib/optedOutCustomers.ts`, `app/opted-out`)
- `listOptedOutCustomers` now returns `{ customers, total, truncated }`.
- The exact total comes from a parallel `count: "exact", head: true` query (so
  the true opt-out count is never subject to the returned-row cap).
- The list itself is capped at `OPTED_OUT_LIST_LIMIT = 200`; when the total
  exceeds the cap, `truncated` is true and the page shows
  "N opted customers · showing the newest 200".
